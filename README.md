# react-native-gesture-handler evidence

Before/after captures for pull requests to software-mansion/react-native-gesture-handler.

Each pair is one scene, one device and one run, differing only in the code under test: `before` is `main` at the pull request's base commit, carrying the pull request's own example screen where the scene is one the pull request adds, and `after` is the pull request's branch. Android pairs are captured on a stock API 34 x86_64 emulator (`google_apis`, 320×640 at 160 dpi) from release builds of `apps/expo-example`, one per variant, cropped below the status bar.
